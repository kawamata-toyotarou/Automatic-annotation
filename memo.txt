1. py --versionでパイソンのversionを確認し、3.14.10であった。
2. py -m venv .venvで	Python標準の venv を実行して、今のフォルダーに仮想環境を作った
   venv とはPythonに標準で付いている、プロジェクト専用の環境を作る機能 たとえば、今回のカメラ開発と別のプロジェクトで違うバージョンのライブラリが必要でも、それぞれの環境で管理できる
3. .\.venv\Scripts\python.exe -m pip install opencv-pythonで仮想環境のPythonで pip を実行し、OpenCVを入れた。必要な numpy も一緒に入った
   OpenCVとは画像や映像を扱う処理をまとめたライブラリ
4. カメラを動かす基本的なプログラムを書いた
5. .\.venv\Scripts\python.exe .\camera.pyで起動できた。
6. gitignoreファイルを作成し、.venv/を追加、.venv という名前のフォルダーと、その中身を無視するという意味
7. 画像保存機能を追加
8. 保存した画像をgitignoreに追加
9. .\.venv\Scripts\python.exe -m pip install ultralyticsで
   YOLOという、画像の中に何が、どこに写っているかを見つける物体検知モデルのシリーズを追加
10.YOLOを用いるプログラムをdetect.pyに追加
11.実際に人間を検出できたのでgitignoreを編集にpush
12.画像を保存してからアノテーションからカメラ時にアノテーションに変更
13.Python 3.14でLabel Studioをインストールして起動した
   仮想環境を作成
   py -m venv .venv-label
   Label Studioをインストール
   .\.venv-label\Scripts\python.exe -m pip install --only-binary=numpy label-studio
   --only-binary=numpy は、NumPyにビルド済みのパッケージを使う指定。
   この方法で Label Studio 1.23.0 と NumPy 2.5.4 が入った。
   通常の起動では、依存ライブラリがPython 3.14で削除された
   pkgutil.find_loader を読み込もうとして ImportError が出た。
   Python 3.14での起動コマンド
   .\.venv-label\Scripts\python.exe -c "import pkgutil; from importlib.util import find_spec; pkgutil.find_loader = find_spec; from label_studio.server import main; main()"
   -c は引用符の中のPythonコードを実行する指定。
   今回の起動中だけ、依存ライブラリが探す find_loader という名前に
   find_spec を割り当ててから、main() でLabel Studioを起動した。
   次回も同じコマンドで起動する。

   PowerShellを開いたまま http://localhost:8080 を開く
14.label studioを起動。projectを作り,labelを付け、画像付きのYOLOでexport
